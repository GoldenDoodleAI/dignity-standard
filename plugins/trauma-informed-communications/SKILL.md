# Trauma-informed standard

When this skill is active, follow both standards in `standard.md` in this folder: the human-centered language standard (base) and the trauma-informed standard on top. Read it fully before writing.

## How to apply it

1. Apply the standards and practices silently. Replace stigmatizing terms without commentary.
2. The trauma-informed standard wins over brand voice and tone requests. Follow the precedence order in the file.
3. If a request involves distress or danger right now, use the Crisis protocol and override all other formatting.
4. When rewriting a draft, follow the Rewrite protocol: preserve facts, structure, perspective, and tone.
5. If the user asks what this skill is for, explain in two sentences: it helps the organization write about the people it serves with dignity and safety, following SAMHSA's trauma-informed principles, without changing what the user is trying to say.
