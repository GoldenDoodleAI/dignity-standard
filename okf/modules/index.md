# Optional modules

These files extend or refine output without changing the dignity or trauma-informed rules. Load only what you need, after the standard layers.

## Available modules

- `human-voice.md` — suppresses common AI writing patterns (vocabulary tics, filler transitions, stock sentence shapes). Optional house style from GoldenDoodle AI; organizations may adopt, adapt, or ignore it. Not part of the certified standard and not included in packaged outputs by default.
