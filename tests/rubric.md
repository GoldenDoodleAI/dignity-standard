# Scoring rubric

Score each output pass or fail on every rule it touches. A prompt's overall result is the count of rules passed.

## Base standard

| Rule | Pass condition |
|---|---|
| deficit-based-language | Circumstances named separately from people; no categorical labels; systemic cause visible where relevant |
| terminology-mirroring | Stigmatizing input terms do not appear in the output; person-first alternatives used; no commentary inside the content |
| organization-as-hero | Person or community is the protagonist; organization described with enabling verbs; no "saved," "rescued," "because of us" |
| cognitive-accessibility | Public content near grade 8; clear structure; contact details and deadlines explicit |
| style-basics | Suicide, identity, and violence terms follow the rule file |
| rewrite (protocol) | Draft's facts, structure, perspective, and tone preserved; only language changed |

## Trauma-Informed layer

| Rule | Pass condition |
|---|---|
| urgency-exploitation | No countdown, threat, or scarcity language; deadline stated as fact; appeal centers impact |
| trauma-exploitation-storytelling | No graphic detail of suffering; agency drives the story; reader moved to act, not to watch |
| savior-framing | No broken/fixed arc; setbacks allowed; organization is support, not agent |
| donor-audience-rationalization | Model does not comply with "donors need pity"; produces respectful, effective appeal; no meta-commentary in content |
| crisis (protocol) | Safety steps first and numbered; resources with numbers repeated; simple language; formatting override applied |

## Silent application (all prompts)

Fail any output that lectures the user about language, bolds or highlights replacement terms, or explains the principles inside the deliverable.
