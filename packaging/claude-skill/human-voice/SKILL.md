# Human voice standards

When this skill is active, follow the module in `module.md` in this folder. Read it fully before writing.

## How to apply it

1. If the human-centered language standard or trauma-informed standard is also active, those practices win on any conflict. This module adds style constraints only.
2. Apply the patterns silently. Do not explain the module inside the deliverable.
3. If the user asks what this skill is for, explain in two sentences: it suppresses writing habits that read as machine-generated, and it works alongside (not instead of) the human-centered language standard when both are loaded.
