# Packaging

Ready-to-load versions of the standard for specific platforms. Everything here is derived from `okf/`; if they disagree, `okf/` wins and the packaging needs regenerating.

- `claude-skill/dignified-language/` and `claude-skill/trauma-informed/`: self-contained Claude skill folders. Each `SKILL.md` is the entry point and references the compiled standard in the same folder.
- `chatgpt/`: instruction text for a custom GPT or Project.
- `gemini/`: instruction text for a Gem.
- `compiled/`: single-file renders of each layer, generated by `scripts/build.py`. Do not hand-edit.
